# 从 v0 到 LSM / 关系拓扑

日期：2026-11-01。状态：方向文档，未实现。本文把“潜意识拓扑与重塑系统”的愿景拆成可验证阶段，避免把隐喻当成已成立的技术能力。

## 1. 术语边界

**LSM（Large Somatic & Symbolic Model）** 在这里是产品叙事，不是已训练的模型，也不代表系统能读取潜意识。当前可落地的是：

- 前语言的交互（身体地图、意象选择、呼吸/强度自报）
- 象征表征（`InnerPlan`）
- 本地、可删除的个人母题记录
- 明确同意下的研究数据

## 2. 阶段

### v0：前语言捕获（已实现）

- 身体地图 + 感觉/强度/呼吸 + 意象碎片。
- 不输入文字；不推断；不保存。
- 验证“选择是否比描述更接近”。

### v1：个人母题日记（已实现）

- 用户自己给母题命名，系统只做并列、回看与导出。
- 本地 `localStorage`；可单条删除、全部删除、导出 JSON。
- 不做因果推断，不做“你是因为童年 X”的解释。
- 指标：用户是否觉得“被看见”，而不是“被分析”。

### v2：同意的多模态研究捕获

- 可选传感器（HRV、呼吸、皮肤电、语音语调）与自报对齐。
- 研究模式，不做临床声明；明确同意、可撤回、可删除。
- 先回答：生理信号与自报意象是否稳定对应？个体差异多大？
- 不把相关性写成“潜意识读取”。

### v3：关系模式地图（高敏感，需单独审查）

- 只记录用户主动写下的触发情境与身体反应。
- 不推断他人心理，不做“匹配分/伤口咬合”结论。
- 用户可以画自己的关系引力场，但不能把他人变成可评分对象。
- 必须有删除、导出、撤回与误解纠正机制。

### v4：临床/干预

- 只有与临床机构、伦理审查、不良事件流程一起做。
- 不承诺记忆再巩固或创伤改写。
- 先做安全性与可行性研究，而不是疗效营销。

## 3. 产品铁律

1. **不推断，只显影**：系统呈现用户选择的碎片，不宣布其意义。
2. **不绕过同意**：去语言化是交互变化，不是伦理豁免。
3. **不把阴影变成指标**：没有潜意识健康分、关系匹配分、连续使用压力。
4. **本地优先**：默认不上传；传感器数据也不默认上传。
5. **可删除、可忘记**：删除必须是真的删除，不是隐藏。
6. **不替代帮助**：强烈痛苦、自伤/他伤风险时停止体验并指向现实支持。

## 4. 技术待验证问题

- 身体部位/感觉标签是否跨人群稳定？是否需要用户自定义？
- 意象库是否文化偏差过强？如何避免引导？
- 生理信号在真实环境中的噪声、基线漂移与个体差异。
- 纵向母题记录的隐私、加密、继承与删除。
- 关系地图的同意、第三方隐私与滥用风险。
- 任何临床声明前的安全性与有效性证据。

## 5. 当前明确未做

- 没有传感器、没有 LSM 模型、没有跨用户数据集。
- 没有关系拓扑、没有匹配、没有临床干预。
- 没有服务端持久化；刷新即丢失。
